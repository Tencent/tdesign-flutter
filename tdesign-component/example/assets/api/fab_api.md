## API
### TFab
#### 默认构造方法

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| icon | Icon? | - | 图标 |
| key | Key? | - | 组件标识，用于区分或保留组件状态。 |
| onClick | VoidCallback? | - | 点击事件 |
| shape | TFabShape | TFabShape.circle | 形状 |
| size | TFabSize | TFabSize.large | 大小 |
| text | String? | - | 文本 |
| theme | TFabTheme | TFabTheme.defaultTheme | 主题 |
