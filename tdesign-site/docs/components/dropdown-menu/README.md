## 何时使用

DropdownMenu 是页面级筛选栏，适用于商品列表等内容的排序、单选筛选和多选筛选。

- 表单中的单项选择请使用 Picker。
- 按钮触发的操作列表请使用 Popover 或 ActionSheet。
- 多选面板中的选择只保存在草稿中，点击“确定”后才提交；遮罩、返回键和切换筛选项不会提交草稿。
