# 测试用例 — issue #924 TFab 暴露 onLongPress 回调

## TC-01

- **前置条件**：使用默认主题的 `TFab`，传入非空 `onLongPress`。
- **操作**：在 widget 测试中对该 `TFab` 执行长按手势。
- **期望**：`onLongPress` 被调用一次。

## TC-02

- **前置条件**：`TFab` 仅设置 `onClick`，未设置 `onLongPress`。
- **操作**：正常短按（tap）悬浮按钮。
- **期望**：仅触发 `onClick`，不因新增参数产生额外断言失败（与既有行为兼容）。

## TC-03

- **前置条件**：应用侧在 `onLongPress` 中执行业务逻辑（例如展示菜单，由集成方验证）。
- **操作**：真机或模拟器长按 `TFab`。
- **期望**：长按事件可达，且不与短按冲突（由业务自行区分）。
