## 行为契约

- NoticeBar 自定义区域保留子组件动作及父目标通知，只有单指主按钮短按（移动不超过触摸阈值、未取消）才报告。拖动、长按、取消及多指不报告；父目标通知不是子动作完成通知。
- BackTop 保留历史 onPressed：无 controller 时通知激活动作；有 controller 时仅在成功回到该 controller 顶部且组件仍挂载时通知。动画中断、controller 解绑/替换不误报；连续点击仍只启动一个回顶过程。已有正常回顶时机不变。
- Tabs onTap 是点按（含重选），Controller 是状态源；SwipeCell 在动画前报告目标开合状态。领域动作与状态请求分别保留。
- Toast 无 ID 使用共享匿名实例 ID 并替换；Loading 为全局单例、重复 show 忽略。公开文档与真实默认值一致。
- API 文档仅选择根库实际导出类型；参数文档在源码维护、产物由正式生成器生成。深色模式示例按当前 API 可编译。

## 兼容性

不改公开名称、签名或正常操作默认值。取消操作误报修复会减少错误回调，依赖错误行为的调用方需迁移；属于回调触发条件变化，按 breaking 交付（正常点击时机及签名不变）。纯命名候选留待独立兼容迁移，不批量替换。
