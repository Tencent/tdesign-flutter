# 文档来源收敛

## 目标与范围

用户指南统一由站点docs维护，根README保留简介和最短接入路径；根CONTRIBUTING保留唯一贡献规范，站点直接读取；包内README和迁移说明由同一个兼容入口生成。迁移范围仅0.2.7到1.0。

## 行为契约

- 迁移源为tdesign-site/site/docs/migration-0.2.7-to-1.0.md，站点原访问路由保持不变，包内副本为MIGRATION.md。
- getting-started、custom-theme、dark-mode、internationalization、faq为独立用户指南；移除README重复长教程，但保留已有内容。
- 站点直接展示根贡献规范，补页面元信息、解析相对链接；合并原站点贡献指南的有效工作流程，不复制规范正文。
- 同步器只维护包内副本及指南中已验证代码片段，支持--check；检查模式不写任何文件，源文件缺失或内容过期返回非零。
- 文档源码Markdown使用小写连字符；README/CONTRIBUTING等工程入口保留惯例。组件页面/API生成链路不变。
- 更新文档来源约定和当前链接。保留历史Spec证据与原始JSON指纹，不以本次搬迁改写历史验证结果。

## 非目标

不调整CI/工作流、CHANGELOG发布链路、组件实现或版本；不宣称57个详细迁移章节/自动摘要或未完成视觉验收已经实现。Spec历史目录与取证工具迁移另行处理。

## 验收

同步及--check幂等、缺失/陈旧检查有效；贡献指南适配链接正确；现有组件契约、主题测试、站点生产构建通过；当前文档相对链接和发布包链接有效。不需要重跑无变化的Flutter生产源码测试。
