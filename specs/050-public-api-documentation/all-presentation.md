## 本轮变更

- 重新生成 57 份 API：类型用途直接置于类型名下，构造和方法分组统一；去掉声明、完整签名、API 示例代码和重复简介标题。
- 除 Popup 外，补齐 208 处方法/函数/回调文档，其中回调 34 处；另补两个 Theme 扩展方法返回值。回调参数不从名称猜测，说明对照实际调用点与上下文数据结构维护。
- Theme copyWith/lerp/merge 的既有组件差异保留，不套用 Popup 的 null 重置或主题快照规则；主题插值不连续的实现仍如实记录。
- 下拉筛选请求被取消/后续操作打断时 Future 也会完成，因此完成不等于达到目标状态；表单控制器未绑定返回 false；Dialog/ImageViewer 的路由 Future 不等同关闭动画结束；Toast 返回标识而非关闭 Future。
- 清理 Button、Icon、Navbar、Switch、Tabs、Theme 中的薄包装和内部层级叙述，保留公开用途、主题与禁用语义；刷新控制器文档保留调用方无需 dispose 的所有权结论。
- Steps 的站点手写迁移表保留全部映射并统一五列，未丢弃迁移说明。
- 新增 `test/tool/api_presentation_test.dart`，逐组件约束表头、五列行、公开类型齐全、无源码代码块/旧章节和非空返回说明；GitHub/CNB 共用测试入口登记该测试及已有 typedef 审计测试。
