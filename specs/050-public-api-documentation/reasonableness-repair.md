## 经验总结

1. **结构验收不等于语义验收**：AST、五列表格、页面可打开只能证明工具和结构，不证明 null、回退、时序、所有权和布局说明准确。
2. **测试通过可能暴露文档错误**：Form 的 `submit() == true` 不代表业务 `onSubmit` 存在或业务请求成功；DateTimePicker 的 fallback 可能触发 DateTime 跨月归一化。
3. **文档必须覆盖运行时五类契约**：null/未传语义、Future 完成时机、资源所有权、Theme/Token 快照与回退、尺寸/滚动/安全区责任。
4. **实现风险与文档缺陷分开**：Theme `lerp` 的额外数据丢失不能通过改文档伪装成修复，应单独做兼容性决策。
5. **候选工具不能替代正式链**：工具 PR 合入 main 后仍需重新解析 resolved ref、生成、`--check`，并确认 autofix 不回退 57 份资产。
6. **未验证必须明确记录**：本轮不宣称 Golden、Figma、设备、全部 Demo 交互或每个业务边界均已完成。
