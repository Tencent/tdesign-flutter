# 逐组件文字排版边界

逐项检查全部 56 个组件目录。单行表示明确的排版契约，不表示当前截图恰好只有一行；可换行段落和调用方 Widget 保持自己的排版。下面是源码处理范围，像素及运行结果以验收记录和本地审图报告为准。

| 组件目录 | 处理与保留边界 |
| --- | --- |
| action_sheet | 列表、宫格、分组标题及取消行按最终 TD 字体/实际列宽增长默认高度；显式 gridItemHeight/itemHeight 仍固定，原生选择、禁用和自定义内容保留。 |
| avatar | 内容为调用方 Widget；保留内容自身排版和显式字体，容器已有 Center。 |
| backtop | 默认圆形按完整文字包围盒增长，半圆两行按自然段落增长；显式尺寸固定，文字不缩放/平移，自定义内容及返回顶部交互保留。 |
| badge | 原有均分留白改为最终解析回退；显式 TD 文字主题不被默认值遮住；custom 内容不改。 |
| button | 内容为调用方 Widget；保留 ButtonStyle、文字子树和显式内容排版；默认行盒居中与尺寸不改。 |
| calendar | 默认数字、星期及月份采用有界的代表文案测量，不逐个排版所有日期；显式 TD 高度、自定义 builder 优先，不兜底任意字体与极小视口组合。 |
| cascader | 导航、选项和说明可换行，保留段落与既有 Row/Center 布局；不按当前短文案强改单行。 |
| cell | 标题、内容、备注是 Widget 插槽，保留主题和显式样式；段落与必填标记不强改。 |
| checkbox | 共享选择卡片采用最小高度与 centerStart，自然段落可增长；显式 TD 字体与自定义指示器、受控值/禁用状态保留。 |
| collapse | 标题、内容、摘要为 Widget；保留显式内容与折叠交互，不强制段落单行。 |
| date_time_picker | 默认选项复用 Picker 单行策略；自定义 itemBuilder 与原生滚动不改；不包含 #1159 的滚动修复。 |
| dialog | 标题、正文和操作是 Widget，便捷确认弹窗同样支持段落；保留内容主题、按钮与换行。 |
| divider | 中间内容是 Widget；保留其显式排版和自定义主题，外部行盒居中不改。 |
| drawer | 内置菜单标题单行复用共享回退；标题 Widget 和 item.content 保持原主题。 |
| dropdown_menu | 标题、列表及网格单行选项复用共享回退；分组标题、按钮内容保持原排版。 |
| empty | 说明文字允许换行，保持段落；自定义说明和图标保持。 |
| fab | 内置文字通过 Button 组合且允许换行；保留 Button 字体、行高和完整自定义 child；不强改单行。 |
| footer | 单行版权文案复用共享回退；链接通过 Link 内容插槽保持排版。 |
| form | 标签、必填标记、帮助和错误文本为段落；保留换行、基线与原生编辑内容。 |
| icon | 图标字形不是正文排版；不修改图标字体、尺寸和绘制。 |
| image | 无内置正文；loading/error builder 保持内容主题。 |
| image_viewer | 内置索引数字均分留白；描述保留换行，图片与关闭交互不改。 |
| indexes | 溢出时保留竖向滚动与点击选择，不溢出保留拖动选择；程序选中项自动显露，首末内置气泡不随索引边界裁切；显式 TD 槽尺寸及 builder 保留。 |
| input | 保留自然行框、普通 Row / Expanded 及原生编辑状态；撤销任意插槽滚动和极小视口自动接管，调用方负责自身内容的合理约束。 |
| link | 文字为调用方 child；保留显式排版、换行、图标与点击能力。 |
| loading | 内置提示均分行框留白、水平提示在真实可用宽度换行；保持动画、refreshWidget 和自定义内容。 |
| message | 普通与跑马灯的单行文字复用共享回退；测量和绘制使用同一解析结果。 |
| navbar | title 为 Widget，保留显式内容样式与主题；NavigationToolbar 居中不改。 |
| notice_bar | 跑马灯和 maxLines=1 文案复用共享回退；多行配置、操作内容与滚动保持。 |
| picker | 默认内置文字/滚轮随内容增长，显式高度及 itemBuilder 保留；滚轮 extent 变化保留选中项而不伪造回调，Popup 组合保留完整滚轮区域。 |
| popover | 内容为 Widget，保留内容主题和段落；已有文本测量与原生布局不改。 |
| popup | 完全保留原有固定头部与 Popup 尺寸、生命周期、插槽主题；删除内部尺寸桥接及未发布的头部高度 API。 |
| progress | 仅内置百分比增长默认胶囊/按钮高度和圆形直径；显式 strokeWidth/circleSize 保留实际绘制尺寸，自定义 label 字体/主题和原生交互保留。 |
| radio | 与 Checkbox 共用卡片最小高度及居中布局；保留默认多行、显式 TD 字体和自定义指示器、受控选择。 |
| rate | 单行评语和数字统一共享回退，保留显式组件/TText 文字主题和半星交互。 |
| refresh | 内置四状态文字按实际约束宽度测量，默认 header/trigger/max 高度适应内容；显式数值及自定义 header 保留，原生刷新状态和回调不改。 |
| result | 标题和描述允许换行，保留正文排版；自定义图标与操作区域不改。 |
| search | 单行输入与 hint 均分留白；操作文字允许换行，显式 style、光标和选择保持。 |
| sidebar | 单行项目保留均分留白，大字体远端选择滚动使用已布局项目实际高度校正；保留显式选中/禁用样式及受控值，不因滚动发出选择回调。 |
| skeleton | 无内置正文；保持占位布局和动画。 |
| slider | 单行刻度和内置数值气泡均分留白；数值、手势、语义与显式 TD style 保持。 |
| stepper | 默认输入与增减按钮适应真实字体，显式 TD 尺寸固定；保持键盘、光标、范围约束与受控值。 |
| steps | 序号均分留白，已声明单行的标题/内容复用共享回退；多行与 customTitle/customContent 保持。 |
| swipe_cell | 内置单行操作文案复用共享回退；builder 的完整主题与内容、手势保持。 |
| swiper | 内置分数数字均分留白；控制按钮、child、customIndicator 主题与手势不改。 |
| switch | 内置单行开关文字复用共享回退；显式 thumbContent 字体行高不再被 height=1 覆盖；自定义内容保持。 |
| tabbar | 已声明单行的项目复用共享回退；允许换行的项目/弹出菜单与 itemWidget 保留段落。 |
| table | 单元格为 Widget；保留自定义内容排版、表格 Theme 和布局，不强制改写内容留白。 |
| tabs | 内置文本 softWrap=false 且无换行符时均分留白；含换行符与 child 保持原排版。 |
| tag | 单行默认复用共享回退；显式 TD 排版、多行配置、图标、关闭与尺寸保持。 |
| text | 公开 TText/TText.rich 不改默认 leading；内部 TTextStyled 仅明确单行/固定数字回退；保留段落、选择、语义。 |
| textarea | 保留正文顶部排版、显式高度和合理固定视口内的编辑/计数；不为无法容纳内容的极小尺寸增加整组滚动兜底。 |
| time_counter | 内置时间数字和分隔符均分留白；显式字体、行高、尺寸和自定义 builder 保持。 |
| toast | maxLines=1 的内置文字复用共享回退；多行配置和自定义内容保持。 |
| tree | 单行 TreeSelect 项目复用共享回退；显式选中/禁用样式、滚动和受控行为保持。 |
| upload | 内置文件名/状态按内容增长默认缩略图，显式 itemSize 固定；部分 TD style 与默认字体正确合并，自定义 builder 和上传/重试/删除等交互保留。 |
