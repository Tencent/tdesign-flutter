# Material 单入口接入与最小 Button 快速开始

## 背景

当前入口未重导出 Material，最小应用仍需要两个 import。

## 目标

- 仅导入 TD 即可使用 Flutter Material 和 TDesign 组件。
- 中英文 README 与站点快速开始按添加依赖、最小导入、最小使用三部分组织，最小使用仅展示 TButton 表达式，不包含布局和事件。

## 非目标

- 不修改组件行为、主题默认值或发布版本号。

## 范围

### 涉及

- TD 公开入口、中英文 README 及脚本生成副本。

### 不涉及

- 现有组件实现与其他未提交改动。

## 行为契约

入口完整重导出 `package:flutter/material.dart`；已有 TD 导出保持不变。用户同时导入 Material 和 TD 时，同一声明不产生歧义。最小导入仅导入 TD；最小使用只展示包含 Text 的 TButton 表达式，供放入已有页面，不包含布局、应用入口或事件，不要求主题初始化；明确不传 onPressed 时按钮禁用。发布前提供固定提交的 Git 源码依赖（含仓库 URL、ref 与包子目录），保证声明的依赖真实包含统一入口；仅将 ^1.0.0 作为该能力随稳定版发布后的接入选项。
