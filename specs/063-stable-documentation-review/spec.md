# 1.0正式版文档复核

## 目标

按用户要求以1.0已发布的口径呈现用户文档；快速开始使用^1.0.0；迁移不占左侧菜单，仍可从快速开始访问。贡献说明使用正式公开文案，FAQ按当前实现重写。主题页明确为色板示例/API，验证其生成代码与实际示例分组一致。主题配置与国际化示例必须来自可运行源码。深色模式合并到自定义主题，旧地址跳转。

## 边界

这是用户指定的正式版文档口径，不执行包发布或修改版本号。保留迁移完整正文与包内副本，不修改CI、测试清单、CHANGELOG和生产组件实现。国际化基于当前完整示例代理，说明业务需实现全部抽象资源字段和其余多语言字段。

## 验收

用户文档无预发布安装说明；左侧无独立迁移/深色模式项，但原路由可访问或跳转；贡献开头无内部工具说明；FAQ不再推荐旧全局context/转换脚本；主题页分组与代码同源并验证明暗/主题重建；主题和国际化代码分析及功能测试通过；站点构建、生成检查和同步通过。
