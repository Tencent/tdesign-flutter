# 本地修复复审

结论：修复后通过，无未处理的阻塞问题。见acceptance.md与results.json当前validation。

| 原问题 | 根因及影响 | 最小修复与回归 |
| --- | --- | --- |
| P2 零行高兼容性 | 新增正数校验拒绝旧版合法的lineHeight=0 JSON | 仅字号要求正数；行高允许0。整数/小数零行高及公共JSON回归 |
| P2 非有限派生行高 | 有限输入仍可能相除溢出，使加载成功却携带Infinity | 公共Font解析及离线输出都校验比例有限；异常JSON返回null，CLI失败保留旧输出 |
| P3 模式选择器识别 | 可选引号未配对，属性内空白处理不完整 | 严格配对引号，允许合法空白；损坏选择器拒绝 |

小数从CSS经JSON到Font全程不取整，未引入人为小数位限制。转换器复用原映射与组件原始默认字体数据；模式专属覆盖共享规则；缺失字体字段按模式补齐。原整数字体构造、缺省字重、显式覆盖及默认主题不变。现有Font.withSize整数API未修改。

验证：Flutter3.32.0/3.47.7各233项主题及工具、20项接入/站点链路、40项css2token测试通过，组件包/Example/css2token严格分析通过；basic.dart 32/32行覆盖。新增测试均已登记。默认视觉不变，无Golden更新。这里记录发布前的本地验证；交付时另行核对PR最终head的远端CI。

边界：工具只支持已说明的生成器根规则，非通用CSS解析器；未知Token/值沿用既有忽略行为。旧pub.dev1.0.0解析器不支持小数输出，业务需使用含修复的组件版本。
