# Demo 体验问题修复

## 范围与背景
PR #1168 同时修复构建日期过期、图片预览删除仅提示、代码入口难发现及 Popover 自定义内容溢出。变更限于示例应用、构建元数据和回归测试，不扩展组件公开 API。

## 行为契约
- 各 GitHub/CNB Web、APK、iOS 构建与本地统一构建脚本在打包前写入实际构建时间和包版本。日期展示按 UTC+8 固定时区格式化；不在打开应用时伪装成当天发布，损坏时间显示未知。
- 代码图标直接打开本页按公开顺序排列的示例清单，选择后展示可滚动代码；移动端和 Web 使用同一资源，缺失或空清单明确提示。原有单示例代码遮罩保留兼容。
- 图片预览确认删除后真正更新 Demo 数据；取消不删除。每次预览传不可变快照，关闭旧预览后再删除并按合法索引重新打开；删除末项回到前一项，删空关闭，可重新体验。不修改组件 onDelete 的通知语义。
- Popover 自定义内容随文字大小撑开，保持默认最小尺寸。

## 验收
覆盖日期生成和非法输入、所有清单资源、Fab 与其他组件的真实代码入口、图片删除取消/首项/末项/删空/重新体验、Popover 深浅色与字体缩放。功能与严格分析在 Flutter 3.32.0 和 3.47.7 验证；Linux Golden 由 CI 验证，不在 macOS 更新基线。
