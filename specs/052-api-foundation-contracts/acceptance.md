## 基础能力边界

- Button：普通与渐变路径均验证独立长按、双动作、单点击、两回调为空禁用，启停动态切换同步 disabled/pressed 与无障碍 enabled；长按不产生点击。新启用规则不新增冗余状态参数。
- Steps：横纵点按当前项仍通知，其他项通知索引；组件不自行改变 value。progress 可只读，selectable 必填回调，display 无交互。
- Loading：所属 Overlay 卸载后恢复、首次绘制前卸载后恢复、旧 Entry 延迟卸载不清除新会话、不透明覆盖层暂时隐藏不销毁会话、普通页面离开保留根 Overlay 全局加载、重复 show 不替换、重复 dismiss 安全。主动关闭、主题捕获、自定义内容及不同图标保留。
- Radio/Dropdown 重选、Checkbox 聚合半选等没有减少；没有为一致性强制添加能力。
