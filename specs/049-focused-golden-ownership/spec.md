# 聚焦 Golden 所有权

## 背景

`base_components` 与 `navigation_components` 把多个无直接组合关系的组件拼在同一张 Golden 中，并由多个组件清单重复登记。单个组件变化会使整个矩阵失败，难以归责和维护。

## 目标

- 移除这两张共享拼盘测试及其四张明暗基线、重复的视觉清单登记。
- 保留每个组件现有的独立 Demo / 聚焦 Golden 和功能测试；不改变组件实现或公开 Demo。
- 将已确认合理的 BackTop Demo 差异更新为 Linux Flutter 3.32.0 基线。

## 非目标

- 不删除单一组件的状态矩阵，如 BackTop 的八状态测试。
- 不删除有明确跨主题契约的 Material 2/3 隔离测试，或按消费者分别截图的 Popup 测试。
- 不改变公开 API、Token、主题或视觉实现。

## 行为契约

视觉回归清单中的每个测试文件有清楚的组件或跨系统契约所有权。公开组件仍由其自身 Demo 的明暗 Golden 覆盖；共享拼盘不再作为其他组件的间接验收依据。

## 验收标准

- [x] 两个拼盘测试及四张基线被移除，清单无悬空引用。
- [x] BackTop Demo 新基线与已确认的当前渲染一致。
- [x] 调度器自测与 Linux Flutter 3.32.0 严格视觉回归通过。
