# 贡献指南与快速开始更新

## 背景

官网贡献指南仍引用旧 API 二进制；快速开始直接复制整份 README，且国际化节选被当作完整实现展示。

## 目标

- 基于 develop 的源码、生成器和 CI 更新贡献操作指引。
- 提供可运行的最小应用与按需求导航；详细主题、明暗切换和国际化内容各有独立教程。
- README 保留项目介绍，官网只提取标记范围内的接入内容。

## 非目标

不修改组件实现、FAQ、更新日志、组件概览或发布工作流。

## 范围

根目录中英文 README、README 同步脚本及其生成副本、官网贡献指南、全局配置教程与菜单。

## 行为契约

- 组件包 README 与根目录对应语言 README 内容完全相同。
- 中文 README 中唯一的 `<!-- getting-started:start -->` 与 `<!-- getting-started:end -->` 包围官网接入内容；官网输出具有快速开始的 front matter，不包含项目徽章、贡献者名单或其他框架介绍。
- 标记缺失、重复、倒置或内容为空时同步失败，在写入任何目标前报告错误。
- 快速开始只包含安装、完整最小应用及需求导航；自定义主题按全局、组件、局部和单实例需求组织，深色模式负责模式切换，国际化负责资源接入，Theme 页继续只展示生成的示例与 API。
- 新教程在全局配置菜单中可访问；旧自定义主题锚点提供跳转入口，避免已有链接落空。
- 组件公开 API、默认行为和最低 SDK 要求保持不变，无 breaking change。

## 验收标准

- [x] 贡献指南引用当前 manifest、公开源码和集中式 CI 入口。
- [x] 最小应用和主题示例可由 Flutter 3.32.0 与本机最新 stable 分析验证。
- [x] 国际化明确全部抽象成员的实现要求并链接完整示例。
- [x] 同步幂等、错误标记不导致部分写入。
- [x] 五个指南页面通过站点构建，需求入口、旧锚点及新菜单经浏览器核对。
- [x] 修改只位于独立工作树的本次范围内。
