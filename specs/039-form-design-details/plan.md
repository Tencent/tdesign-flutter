# 实施方案

## 技术方案

在 Form Demo 中为排布按钮和 Switch 提供语义 Token 样式；移除水平尾部对齐；性别项按布局选择标准或紧凑 Radio 组合；统一底部按钮顺序和配色。

## 影响范围

| 范围 | 文件或模块 | 影响 |
| --- | --- | --- |
| 组件 | 无公共组件改动 | 无 |
| 测试 | Form Demo | 增加布局与主题断言 |
| 示例 | Form Demo | 对齐公开展示 |
| 文档 | Spec | 记录 Demo 契约 |

## API 变化

- 无。

## 风险与取舍

- 竖向性别项使用现有纯指示器能力组合紧凑布局，保持状态与无障碍语义。

## 验证策略

- 单元测试：既有 Form 组件测试。
- 集成或 Widget 测试：Form Demo 非视觉与 Golden。
- 静态检查：`flutter analyze --fatal-infos`。
- 人工验收：Android 真机分别核对水平、竖向和禁用态。
