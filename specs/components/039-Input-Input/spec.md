# Input 设计说明

## 背景与目标

以下保留设计形成时的问题与依据；已修复的问题不表示当前代码仍有同一缺陷。

Form 标签和输入前后缀间距相互叠加，视觉修补容易改变复合操作区。

实际 Demo 中横向单列表单标签字号偏小、纵向布局未区分字号，输入框图标间距不足，错误态和超长标签示例也未居中。本次统一组件 Token 与公开 Demo 配置。

## 范围与非目标

### 不涉及

- 不把所有横向表单默认改成居中，不新增重复的像素参数。

## 最终方案与行为契约

- 横向 `TFormItem` 标签使用 `fontBodyLarge`，纵向标签使用 `fontBodyMedium`。
- `TInput` 左侧仅图标前缀与编辑区使用 `spacer16`；尾部插槽继续使用
  `spacer8`，避免改变单位文字、验证码图片和复合操作区的既有间距。
- 图形验证码和手机号验证码操作区均保留内容左侧的 1dp 垂直分割线，分割线
  与右侧内容间距为 16dp。
- Form 默认垂直对齐仍为 start；需要居中的错误态和超长标签 Demo 显式设置 center。
- Theme 显式样式继续覆盖默认 Token。

## 关键决策与取舍

| 决策 | 理由与取舍 |
| --- | --- |
| 采用的方案 | 表单布局与编辑器视觉分别归 FormItem 和 Input，前缀和尾部插槽按各自内容职责布局。 |
| 保留的边界与代价 | 默认 Token 可由受支持的组件主题和实例样式覆盖，保留原生编辑与调用方自定义内容。 |

## 兼容性与迁移

本次只整理设计记录，不据此新增 API、改变默认值或判断全部兼容。后续接口删除、类型收紧或默认行为变化按最终源码和迁移指南核对。
