# Slider 设计说明

## 背景与目标

以下保留设计形成时的问题与依据；已修复的问题不表示当前代码仍有同一缺陷。

公开示例与默认轨道、刻度和游标几何不一致。

## 范围与非目标

### 目标

按小程序公开 Demo 的可见矩阵，对齐单/双游标、数值、非零起点、刻度、禁用、胶囊与垂直示例，并建立独立行为与视觉回归。

## 最终方案与行为契约

### API Review

- `TSlider` / `TRangeSlider` 以值类型区分单值与区间，避免 `range` 布尔参数改变 value 类型。
- `value + onChanged` 遵循 Flutter 受控模式，`onChanged == null` 表示禁用，不引入 `defaultValue`。
- 数值和刻度由 `showThumbValue` / `showScaleValue` 与 formatter 负责；`showThumbValue` 持续显示拇指数值，非零起点沿用 `min/max/divisions`。
- 垂直方向由 `RotatedBox` 组合，胶囊外观由 `SliderTheme` 组合；二者不新增与 Flutter 框架重复的 API。
- 视觉字段由 TSliderThemeData 覆盖 TDesign Token；外部 SliderTheme 和 ColorScheme 不反向配置；token 默认提供 Gy1 描边 thumb、品牌色轨道、Gy4 未激活轨道、区分前后轨道的禁用色，并以禁用文字 token 绘制禁用态常驻数值。

- Demo 的公开区块与内部 18 个 Slider 实例在数量、顺序、类型和默认值上与固定小程序基线一致。
- 所有可交互实例均由页面持有状态；禁用实例 callback 为 null。
- 垂直组合仅旋转轨道和 thumb，数值与刻度文字保持正常阅读方向；最小值位于顶部，数值向下递增，与设计稿一致。
- `TRangeSlider` 在构建时拒绝落在 `min/max` 外的范围值。
- 不新增公开 API；修正既有 `showThumbValue` 语义和默认视觉属于缺陷修复。

### 端点几何与刻度对齐

- 以小程序实测 commit `a2aeed69163b6da423c99b66ff780c10043a4553` 为基准：胶囊 thumb 沿行程方向距离外沿 3px（中心内收 13px），默认横截面两侧留白 2px。普通轨道 thumb 中心位于可见轨道端点；连续/离散、单/双游标共享行程，刻度不改变端点。
- 水平刻度文字中心与各值的实际 thumb 中心对齐；RTL 使用同一方向映射。
- 垂直示例的数值与刻度中心与旋转后的 thumb 中心对齐，连续普通轨道不额外内缩半个轨道高度。
- 验证覆盖水平/垂直、连续/离散、单/双游标，以及真实拖动到 0/100 后的明暗截图。

## 关键决策与取舍

| 决策 | 理由与取舍 |
| --- | --- |
| 采用的方案 | normal/capsule 的轨道与刻度属于组件形态，由组件实现，不由 Demo 局部主题补画。 |
| 保留的边界与代价 | 保留 Flutter 原生手势识别、范围选择和受控值；单值持续拖动按当前几何位置映射，避免缩放后累积位移失真；区分可见轨道长度与完整 thumb 命中布局，不能靠缩短轨道容纳 thumb。 |

## 兼容性与迁移

本次不新增或删除公开 API，不改变构造参数、类型和默认值。正常尺寸且两端可容纳时保留连续范围 8px 最小中心距；离散同刻度和直接传入相等端点继续支持。接近取值边界或布局受限时约束间距，避免非法回调。端点、刻度位置与垂直可见长度的有意视觉修复不等于保持旧错误像素。

## 验收标准

- 默认、显式配置、关键状态与边界行为符合最终方案；功能、视觉和人工路径按适用范围分别验收。

验收标准描述应满足的行为，不表示已执行或通过；执行范围与证据见 [acceptance.md](./acceptance.md)，剩余事项只在 [tasks.md](./tasks.md) 维护。

跨组件配置职责见 [Theme 契约](../../engineering/048-Theme-configuration-contracts/spec.md)，视觉方法见 [Golden 规范](../../engineering/044-Testing-golden-regression/spec.md)。

### 可配置几何的统一解析

- 组件、刻度文字与垂直组合复用未导出的内部几何解析器，不新增包公开 API。可见轨道与 thumb 行程分别表达，传给 Material 的坐标轨道不携带绘制厚度，避免 SDK 隐式内缩成为第二计算源。
- 胶囊轨道厚度至少为默认 20px thumb 加两侧各 2px 留白；较大的 spacer3 在可用横轴空间内生效。宽度不足时先收缩外部内缩，仍不足则按比例缩小轨道与 thumb，并保留正行程；零宽度安全退化，不触发绘制断言。
- 普通 trackHeight 只控制可见厚度，连续/离散不改变行程；尺寸参数非法值安全归零。水平方向的布局留白保障 thumb 本体在约束内；垂直组合使用完整设定长度，普通 thumb 跨过轨道端点属于预期效果。
- 离散输入的控件位置按 min/max/divisions 吸附至最近刻度；格式化回调及默认数值标签继续使用业务传入的原始受控值，保留既有显示和回调契约。
- 垂直组合明确采用局部 LTR 坐标，保持最小值在顶部；文字保留宿主方向。禁止示例另行硬编码轨道厚度。

### 小程序端点实测对齐

- 垂直组合通过未导出的内部轴向布局配置解析几何，不继承水平端部留白；200px 设定长度对应 200px 可见轨道，相对可见轨道普通 thumb 中心为 0/200，胶囊为 13/187。轨道外预留 thumb 半径加半描边的完整命中空间（默认各 10.5px），布局总长与可见长度分开表达，不能因命中留白缩短轨道。
- 不保留旧公式开关、不按 SDK 版本分支，不用负 padding、平移或 Demo 局部主题修补。轨道绘制、交互行程、thumb、数值与刻度复用同一解析结果。

### 交互尺寸和双轴约束

- 连续双游标在两端可容纳时保留既有正常尺寸8px最小中心间距，即使当前受控区间小于8px；间距随几何缩小，并由两个游标到各自取值边界的空间限制，避免越界。离散同刻度、业务直接传入的相等端点仍按既有规则支持。thumb 首选尺寸和绘制尺寸读取实际布局的同一 metrics，不在回调层截断非法值。
- 轴向空间决定缩放和最小有效行程，厚度只在横轴可用空间内解析，不能挤占端部布局留白而改变可见长度。声明长度与控件总宽度由同一几何模型精确换算；覆盖短长度与大厚度组合。
- 持续拖动、拖动中宽度变化、普通/胶囊、单/双、连续/离散和 RTL 均须双版本回归；零宽度安全退化，恢复宽度后继续正常操作。
- 正尺寸变化保留已开始的手势，指针坐标映射到当前行程；退化为零时只结束滑块已拥有的交互一次，不打断父滚动。恢复后可开始新手势。

### Golden 按独立缺陷覆盖

- Demo Golden 由三组明暗基线组成，共6张：默认完整页、端点矩阵、视觉边界矩阵；组件Golden单独保留1张。默认页负责分组、顺序、初始状态及禁用配色，参数组合不重复采样页面壳。
- 端点矩阵从真实公开Demo操作后的图像采样18个代表区域，覆盖普通/胶囊、水平/垂直、连续/离散、单值0/100、完整区间，以及数值、刻度、分段和thumb的对齐。完整区间在一个场景中同时展示两端。
- 边界矩阵保留8个代表区域：普通粗轨道近端点标签、普通/胶囊RTL、48px离散胶囊、8px连续胶囊、8px横轴约束、192/240主题厚度约束。测试专用来源与公开示例均保持原尺寸采样，不复制Slider几何实现，不改变公开Demo。
- 持续拖动、拖动中缩放、零尺寸、回调顺序与取值、父滚动、键盘、离散吸附、小胶囊token及宽泛参数组合由现有组件/功能回归验证。中间拖动、吸附后等效值等无独立视觉结构的状态不再各自新增图片。
- 每个保留Golden必须对应可见风险；源场景数量及覆盖映射记录在acceptance.md关联的验证记录中。矩阵可读性和缺陷检测能力优先于参数穷举数量。
