## 取舍与验证边界

曾考虑全局取消连续双游标最小像素间距；因会扩大连续回调的输出范围、影响依赖正跨度的业务，最终撤回。早期 2px 行程留白、普通离散内缩和 168px 垂直长度也不再作为当前契约；最终设计以 [spec.md](./spec.md) 为准。

上述结论为本地验收，不代表远端 CI 或设备验证。Skyline、微信真机及平台构建未执行；长 formatter 文本的全局展示策略不属于本次扩展范围。最终推送 SHA 的远端检查独立确认，待办见 [tasks.md](./tasks.md)。早于本次指纹的历史候选不作为当前通过证明。

## 按独立缺陷收敛Golden（当前本地结论）

本轮基于已提交生产候选，仅调整测试组织和Spec。生产组件、公开Demo、生成产物、字体和组件测试均未改。前一轮本地候选把Demo基线32→16张，本轮进一步按独立可见风险收敛为6张，组件Golden仍为1张；新的指纹、覆盖对应关系及执行结果见 [独立缺陷验证记录](./evidence/golden-defects-20261027.json)。此前34次及16次比较保留各自验收身份，不作为当前6次比较的证明。

| 职责 | 当前基线 | 保护的风险 |
| --- | --- | --- |
| 默认完整页 | page_light/dark | 分组、顺序、默认中间值、禁用状态、明暗配色 |
| 端点矩阵 | endpoints_light/dark | 普通/胶囊、水平/垂直、连续/离散的0/100与完整范围；thumb、数值、刻度及分段对齐 |
| 视觉边界矩阵 | boundaries_light/dark | 粗轨道近端点、RTL、窄尺寸、横轴缩小及大厚度约束 |
| 功能回归 | 不另建Golden | 回调、8px规则、持续拖动/缩放、零尺寸、滚动、键盘、吸附及广泛参数组合 |

- Demo基线与比较次数均16→6；含组件总基线17→7。两张默认页逐字节不变，四张新矩阵原尺寸内容与此前对应区域独立对照，52个代表区域像素变化均为0。
- 两版各17个Demo和179个工具测试通过，组件与Example严格分析零诊断；86个组件回归用例及其生产代码保持原样，复用已提交生产候选的有界结果，未在本轮重复执行覆盖率门禁。
- Linux四张新矩阵先检查实际图和旧区域，再建立一次基线；随后同命令不带更新参数复验，6个Demo和1个组件Golden精确通过，未放宽容差。
- 在隔离临时副本故意重现端点内距偏差1px、取消厚度上限，端点矩阵与边界矩阵分别出现预期像素失败。正常交付源码和公开Demo未因此修改，反例结果独立于正常通过记录。
- 参数笛卡尔积的额外图片、重复中间拖动图和吸附/最小厚度等等效视觉状态已移除；对应计算和交互仍由现有功能回归覆盖。本轮未提交、未推送，远端CI和设备不属于当前结论。

## 回调和正常尺寸兼容修复（当前候选）

- 单值与双值非刻度输入保留原始受控值用于自定义 formatter 和默认数值标签；控件位置仍吸附刻度。正常尺寸的连续双游标，即使受控区间窄于8px，只要两端有足够空间仍采用8px；不足时由同一几何模型限制，防止产生越界值。
- Flutter 3.32.0 Linux 与 3.47.8 macOS 分别执行88项 Slider 组件功能回归、17项 Demo 功能回归及组件严格静态分析，均通过。真实拖动覆盖普通和胶囊窄区间，验证间距及回调取值；既有用例覆盖约束、缩放、两端、RTL 与生命周期。
- Linux Flutter 3.32.0 按 `TDESIGN_DEMO_TEST_MODULES=false` 执行6项 Demo Golden 和1项组件 Golden，使用默认精确比较器，均通过；本轮没有更新基线。未针对当前候选重跑全项目工具测试、覆盖率及生成产物检查，历史结果不作为当前候选通过证明。
- 本轮 Slider 构造参数、字段、方法、枚举、formatter typedef 与包导出经 AST 对照 develop 均未变化；仅恢复 formatter 输入和可容纳情况下原有最小间距。靠近取值边界时的间距约束是为避免非法回调而保留的修复，不能宣称所有边界行为与旧版逐项相同。相关本地测试和文件哈希见 [本轮验证记录](./evidence/compatibility-20261027.json)。
