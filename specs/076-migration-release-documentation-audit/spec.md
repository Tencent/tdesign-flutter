# 0.2.7 到 1.0 发布文档核对

## 目标

以0.2.7真实发布包/标签和1.0候选公开入口为依据，核对迁移覆盖、删除能力、生成文档/示例一致性及发布说明。基线develop596e013d、版本候选7d3cb3e2；版本PR独立保留。

## 契约

逐项记录388项（原383项及本次补出的5项）旧自有导出和57个组件入口，区分导出存在、源码语义审查、可运行消费和设备视觉证据。不能将名称相近、API生成成功、关键词命中当成语义等价或完整迁移证明。历史Spec058机器报告不覆盖改写，新核对单独留证。

修复确定的错误迁移描述，给删除能力明确替代方向/限制。正文仍只维护站点迁移指南，通过原同步器生成包内副本；组件定位复用已有分组和目录，不新增搜索或57份独立文档。

## 非目标

不改组件API、生产实现、版本号、CI或Golden；不宣称覆盖所有业务代码、继承成员、私有深层导入或真实设备视觉。完整CHANGELOG仅通过既有发布流程维护，本次整理候选说明供Review。

## 验收

旧包来源校验、当前导出清单、388/57覆盖和有效目标逐项留证；源码与具体文案相互核对。既有迁移consumer和新增真实迁移用法在两SDK运行，API/片段生成检查与同步检查通过。报告明确剩余内容缺口，不能强行把五项发布文档检查全部勾选。
