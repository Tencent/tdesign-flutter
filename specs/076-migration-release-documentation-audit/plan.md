# 核对方法

1. 固定候选SHA，验证0.2.7缓存包与仓库标签的lib文件一致；通过Dart AST追踪自有exports及show/hide，提取每个旧声明的源文件。
2. 与当前API审计输出及迁移附录逐行对应，检查目标是否存在、是否误配、是否只提供泛化提示；按57个组件核对旧构造/当前参数与指南说明。
3. 修正确定的错配并补充删除能力边界；每个组件提供稳定的现有条目锚点，旧类型附录指向实际组件改法。
4. 以实际可复制示例/外部consumer验证重点迁移，生成产物从源同步；保留未覆盖业务和设计验收缺口。
5. 对自动发布草稿按来源PR、重复、分类、漏项和失效链接核对，将整理候选附于版本PR，保持待最终确认。
