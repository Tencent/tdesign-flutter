## 背景与目标

以下保留设计形成时的问题与依据；已修复的问题不表示当前代码仍有同一缺陷。

公开示例、内部调试区块、代码展示和构建元数据混在一起，会掩盖组件缺陷并造成状态丢失。


## 范围与非目标

覆盖本工程职责的设计与验收边界；不将目录整理扩展为新的组件能力、发布动作或远端配置修改。

## 最终方案与行为契约

### 示例与组件边界

公开示例只管理示例数据、状态和外部排布，不通过局部 Theme、装饰、位移或裁剪掩盖组件缺陷。组件视觉与交互归对应组件 Spec，Golden 方法归 Testing Spec。

公共 Demo 页面壳统一容器表面与间距；可复制的公开示例 Widget 不依赖页面壳、代码映射或测试区块。框架重构须保持既有页面像素与交互，并同步生成的 API 和代码片段来源。

### 调试区块

Debug 默认展示内部验证区块，Profile/Release 隐藏。显式页面开关用于测试或内部调用；公开 Golden 的固定开关由视觉回归规范维护。

### 体验契约

- 各 GitHub/CNB Web、APK、iOS 构建与本地统一构建脚本在打包前写入实际构建时间和包版本。日期展示按 UTC+8 固定时区格式化；不在打开应用时伪装成当天发布，损坏时间显示未知。
- 代码图标直接打开本页按公开顺序排列的示例清单，选择后展示可滚动代码；移动端和 Web 使用同一资源，缺失或空清单明确提示。原有单示例代码遮罩保留兼容。
- 图片预览确认删除后真正更新 Demo 数据；取消不删除。每次预览传不可变快照，关闭旧预览后再删除并按合法索引重新打开；删除末项回到前一项，删空关闭，可重新体验。不修改组件 onDelete 的通知语义。
- Popover 自定义内容随文字大小撑开，保持默认最小尺寸。

## 关键决策与取舍

## 兼容性与迁移

本次只整理设计记录，不据此新增 API、改变默认值或判断全部兼容。后续接口删除、类型收紧或默认行为变化按最终源码和迁移指南核对。

## 验收标准

验证真实页面入口、示例代码清单、图片删除取消/末项/删空/重新体验、Popover 内容与字体缩放、构建日期和调试区块的构建模式差异；功能和视觉分别验证，不沿用历史截图声称当前候选通过。

验收标准描述应满足的行为，不表示已执行或通过；执行范围与证据见 [acceptance.md](./acceptance.md)，剩余事项只在 [tasks.md](./tasks.md) 维护。

## 站点历史转换清理

站点只消费现行 Flutter 示例/API 指令；移除无消费者的 WXML/JS/WXSS/JSON 占位符转换、空 demo 注入和旧覆盖率注释。保留仓库文档链接适配、Flutter 代码/API 资产读取、BASE_URL 图片改写及站点壳的空 demos 对象。无需迁移组件 API。验收执行现有站点测试、文档资产检查和构建；检查公开文档无旧占位符或小程序示例资产。


## 文档锚点与历史恢复

文档内容就绪后展开锚点所在的 details 祖先并定位；按浏览器历史条目 position 保存并恢复阅读位置和折叠状态，同 URL 不同条目互不覆盖，取消旧导航的等待。不改变指南示例、Flutter 预览或主题功能色板。

Markdown 的空锚点段落紧邻 details 时，该锚点标记后续折叠章节，应展开相邻 details；段落有普通内容时不展开。保留原文档 ID 与结构，由导航层适配实际渲染结构，避免重写同步迁移正文。


## 主题功能色板

按当前主题实际可解析的 Token 枚举 brand/error/warning/success 色板，支持分类数量不等、稀疏和空配置及别名，不根据索引伪造键名；主题变化时重新读取。不修改主题指南、国际化或站点导航。


## 可运行接入指南

快速开始提供可点击计数器；主题示例支持资源加载和默认/业务配色对比，复用初始化的主题对象；国际化指南包含代理所需的完整资源及语言切换。指南片段、主题 JSON 和 ARB 来源同步生成。指南和组件共用 Flutter 手机预览，保留首次加载、reload 主题同步和卸载清理。沿用既有 Documentation 命名；不修改功能色板或全站导航。

主题指南及其独立场景保留局部 MaterialApp 的主题与本地化环境，但只通过 builder 渲染内容，不创建内层 Navigator。iframe 的路由与浏览器地址由 Example 宿主唯一管理，切换主题及首次挂载不得把指南路由覆盖为首页。刷新 iframe 后仍进入原指南，并重新同步宿主当前外观；计数、输入和临时选择按重新启动的初始状态处理，不承诺跨刷新保留。

迁移指南正文的同页锚点在每次普通点击时先展开目标，重复点击相同 hash 也必须有效；修饰键及新窗口链接保持浏览器默认行为。附录通过显式 data-expand-details 关联折叠表格，不依赖跨段落猜测。


## 迁移指南组织与查找

保留 0.2.7 到 1.0 的稳定路由、已有显式锚点及完整旧类型对照。开头明确基础迁移与发布后开发分支变更的边界；后续注意事项独立分节，用户正文只保留可执行调整，不保留 PR 分工、授权或 Golden 流水。禁用语义直接写 null。组件索引负责摘要，复杂改法提供可运行源生成的示例；目录子标题标注所属任务，并为旧目录锚点保留兼容入口。

按用户要求不提供专用搜索控件；通过直接可见的组件分组表格、目录和原生页面查找定位。开头阅读路径合并，组件摘要不复述已有详细改法；附录共用说明集中维护，保留全部 388 项映射及各项特有差异。包内 Markdown 保留原生目录和完整对照表。验收逐项检查正文/自动目录的所有链接，区分本地路由与 API 页签、折叠深链接、生成副本和正式官网的可访问性，不用 HTTP 200 代替路由内容正确性。

站点迁移页使用统一页头，正文不重复展示同一一级标题；保留原标题片段地址，包内 Markdown 仍保留独立一级标题。

迁移组件索引采用六组直接可见的三列表格（组件 API、旧入口 → 新入口、关键变化与改法），分组显示数量；保留 57 个组件与 388 项旧类型对照。目录只展示 14 个主要章节，正文小节和旧锚点保留。表格主题配色与间距在文档范围生效，列宽按组件与附录内容分别安排；窄屏只保留表格内部滚动，不强行兼容整站侧栏及页头。

本次独立文档不依赖 #1202 的主题或导航修复。组件索引使用普通 section 与原生锚点，避免跳转目标处于关闭的折叠区域；旧类型附录保留原生 details/summary，由读者点击展开，不承诺自动展开或恢复折叠历史状态。

仓库级测试统一放在根目录 `test/`：`test/scripts/` 保存脚本测试，共用 runner-tests 入口执行该目录全部 Node 测试；`scripts/` 保留运行和生成脚本。迁移文档及 Token 的消费验证属于仓库开发基础设施：项目位于 `test/migration_consumer/`，运行入口为 `test/migration_consumer/run.dart`，用户迁移示例唯一维护在 `tdesign-component/example/lib/migration_examples.dart`，站点负责指南正文和片段展示。运行器从自身路径定位仓库并在临时目录验证对组件公开入口的消费，不依赖调用者当前目录。文档生成读取 Example 源码，验证运行器将同一源码复制到临时消费者；GitHub/CNB 复用仓库级工具入口，不在验证项目内维护示例副本。

迁移消费验证不保留没有独立行为意义的测试：公开构造与参数类型由静态分析验证；运行时测试聚焦实际指南函数的交互组合及少量公开 API 消费契约。Text、Avatar、Tag 样式等通用组件行为复用组件回归，不为静态可检查的构造列表或已有挂载覆盖增加重复用例。目录去除 fixtures 中间层，按 Example 中的 migration_examples 与验证项目内的 public_api_examples 区分用途，包名统一为 tdesign_migration_consumer。
