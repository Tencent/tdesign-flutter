## 背景与目标

以下保留设计形成时的问题与依据；已修复的问题不表示当前代码仍有同一缺陷。

公开示例、内部调试区块、代码展示和构建元数据混在一起，会掩盖组件缺陷并造成状态丢失。


## 范围与非目标

覆盖本工程职责的设计与验收边界；不将目录整理扩展为新的组件能力、发布动作或远端配置修改。

## 最终方案与行为契约

### 示例与组件边界

公开示例只管理示例数据、状态和外部排布，不通过局部 Theme、装饰、位移或裁剪掩盖组件缺陷。组件视觉与交互归对应组件 Spec，Golden 方法归 Testing Spec。

公共 Demo 页面壳统一容器表面与间距；可复制的公开示例 Widget 不依赖页面壳、代码映射或测试区块。框架重构须保持既有页面像素与交互，并同步生成的 API 和代码片段来源。

### 调试区块

Debug 默认展示内部验证区块，Profile/Release 隐藏。显式页面开关用于测试或内部调用；公开 Golden 的固定开关由视觉回归规范维护。

### 体验契约

- 各 GitHub/CNB Web、APK、iOS 构建与本地统一构建脚本在打包前写入实际构建时间和包版本。日期展示按 UTC+8 固定时区格式化；不在打开应用时伪装成当天发布，损坏时间显示未知。
- 代码图标直接打开本页按公开顺序排列的示例清单，选择后展示可滚动代码；移动端和 Web 使用同一资源，缺失或空清单明确提示。原有单示例代码遮罩保留兼容。
- 图片预览确认删除后真正更新 Demo 数据；取消不删除。每次预览传不可变快照，关闭旧预览后再删除并按合法索引重新打开；删除末项回到前一项，删空关闭，可重新体验。不修改组件 onDelete 的通知语义。
- Popover 自定义内容随文字大小撑开，保持默认最小尺寸。

## 关键决策与取舍

| 决策 | 理由与取舍 |
| --- | --- |
| 采用的方案 | Demo 负责示例状态和外部布局，组件负责自身视觉；公开片段与实际运行源码共用来源。 |
| 保留的边界与代价 | Debug 保留内部验证，公开 Profile/Release 和 Golden 排除内部区块；不以页面补偿制造视觉正确。 |

## 兼容性与迁移

本次只整理设计记录，不据此新增 API、改变默认值或判断全部兼容。后续接口删除、类型收紧或默认行为变化按最终源码和迁移指南核对。

## 验收标准

验证真实页面入口、示例代码清单、图片删除取消/末项/删空/重新体验、Popover 内容与字体缩放、构建日期和调试区块的构建模式差异；功能和视觉分别验证，不沿用历史截图声称当前候选通过。

验收标准描述应满足的行为，不表示已执行或通过；执行范围与证据见 [acceptance.md](./acceptance.md)，剩余事项只在 [tasks.md](./tasks.md) 维护。
