## 背景与目标

以下保留设计形成时的问题与依据；已修复的问题不表示当前代码仍有同一缺陷。

主题控制器和生成器导出的 CSS 不能直接作为应用主题使用，稀疏字体、浅深模式和通信生命周期需要一致转换。


## 范围与非目标

本 Spec 统一主题输入链路：控制器或生成器输出 CSS → `css2token` 转换 → 浅/深 Token JSON → `TThemeData.fromJson` → 预览或业务应用。它负责转换与同步，不替代组件 Token/Theme/实例 API 的配置职责，不机械扩展组件 API。

## 最终方案与行为契约

### 在线预览

- 官网发送原始 light/dark/extra CSS 和模式，Example 复用纯 Dart `packages/css2token` 转换；转换库不依赖浏览器或 Flutter。
- 只接收同源父窗口的有效消息；首帧监听完成后 ready，iframe 新建、加载或重新挂载收到当前主题；重复消息去重，卸载时释放监听。
- 仅转换实际提供的 Token，缺失或非法字段不生成默认覆盖；公共 CSS 名称与 Flutter Token 名称显式映射，不复制控制器默认数值。
- 浅深配置独立；颜色、字体、圆角、阴影、尺寸和间距按其已有消费链更新。组件是否消费某个 Token 由运行验证 Spec 裁定，不能仅凭转换 JSON 宣称全组件生效。

### 离线导入

- Font.fromJson 接受整数及小数字号/行高，保留精度和 lineHeight/size 比值；Font 整数构造签名不变。缺省字重仍为400；无效类型、非有限数、非正字号、负行高或计算后非有限行高比例及超出1..9的字重拒绝，TThemeData.fromJson保持失败返回null。
- 仓库 Example 提供离线转换工具：完整生成器theme.css→命名浅/深JSON→公共TThemeData.fromJson。支持当前生成器的:root、:root.dark和theme-mode选择器，模式规则优先于共享规则，同类规则按源码顺序合并。不实现通用CSS层叠/媒体查询；不支持的规则明确报错。
- 复用css2token映射，不复制映射。字体缺失字段从组件库原始默认JSON按模式补齐，不复制默认值；未导出组继续由组件库默认继承。输出包含完整字体size/lineHeight/fontWeight，显式CSS覆盖优先。
- 不发布css2token、不扩大组件CSS导入API，不改组件默认值、token映射或站点协议。业务运行时只依赖组件库和生成JSON。

保留小数字号与行高精度，显式零行高有效；字号为正有限数，行高非负有限数，派生比例必须有限。严格验证模式选择器和引号，不接受不支持的层叠规则；转换失败不得覆盖已有输出。

### 预览与指南

亮暗切换、中性色板和自定义主题示例用于展示同一套主题链路；用户操作说明维护在 [主题指南](../../../tdesign-site/site/docs/custom-theme.md)，不再为指南布局或阶段复核保留独立 Spec。

## 关键决策与取舍

| 决策 | 理由与取舍 |
| --- | --- |
| 采用的方案 | CSS 转换集中到纯 Dart css2token；在线预览与离线导入共享映射，浏览器通信留在 Example。 |
| 保留的边界与代价 | 只实现明确支持的生成器规则，不实现通用 CSS 层叠；拒绝无法解释的输入，保留小数与零行高语义。 |

## 兼容性与迁移

本次只整理设计记录，不据此新增 API、改变默认值或判断全部兼容。后续接口删除、类型收紧或默认行为变化按最终源码和迁移指南核对。

## 验收标准

覆盖在线消息生命周期、非法与跨源消息、完整 CSS 导出离线转换、浅深 JSON 加载、小数与零行高、实例覆盖优先级。旧整数 JSON 保持兼容；实时消息协议与离线 CSS 解析范围分别验证。

验收标准描述应满足的行为，不表示已执行或通过；执行范围与证据见 [acceptance.md](./acceptance.md)，剩余事项只在 [tasks.md](./tasks.md) 维护。
