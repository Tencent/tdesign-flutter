# 发布候选与自动化核对

本文件是待核对清单，不记录旧远端规则或旧 CI 结果为当前事实。

本地工作流现状：`auto-changelog.yml` 为 release PR 生成日志，并处理确认评论的写回；`tag-push.yml` 在 tag 创建后将当时的 develop 合并到 main。仓库已经没有旧 `auto-release.yml`，不得沿用“合并版本 PR 自动创建 tag”的旧描述。

- 核对最终候选的实际 CI 入口、过滤条件与执行日志；Golden 文件存在或已登记不等于每个状态都执行。
- 远端保护规则、扫描结果、审批和自动修改后的 head 必须在发布时实时检查，本轮未查询。
- 核对 tag 指向的候选与发布构建来源；tag 触发的同步读取移动 develop，不能默认推定 main、站点或包与 tag 完全一致。
- 没有能够证明来源一致的自动化时，由发布流程明确冻结并核验，不能通过旧工作流设计或历史绿灯替代。

本次不修改工作流、远端规则、tag 或发布产物。
