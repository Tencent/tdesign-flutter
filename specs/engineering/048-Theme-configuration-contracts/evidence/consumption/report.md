# 组件配置收敛：历史证据摘要

## 范围与结论

本报告概括 2026-09-27 至 2026-10-15 的组件 Theme/API 审查，不是当前源码或发布批准。早期同名字段扫描仅说明当时公开同名候选归零，未覆盖异名同义字段、完整 style 或包装组件，不能证明全仓语义收敛。

最终所有权、Material 隔离和跨组件裁定以 [设计契约](../../spec.md) 为准；组件细节见各组件 Spec。[所有权表](../../ownership-table.md) 保留逐字段判定，[阶段迁移清单](../../migration.md) 保留当时 API 迁移依据，不作为完整版本升级指南。

## 验证范围与边界

- 早期聚焦验证包括组件、Demo、覆盖率和 Linux Golden，覆盖范围随批次不同，不能累加为一次全量通过。历史 shader 解码异常与双 SDK 缓存串用属于环境约束，不作为组件通过证据。
- 2026-10-03 的仓库外独立消费包在 Flutter 3.32.0 / 3.47.0 严格分析及各 10 项测试通过，仅证明所列替代调用；范围见 [独立消费验证](../../migration.md#独立消费验证与发布边界)。不证明未知业务应用迁移无风险，也不要求所有未知第三方升级才可发布。
- 原报告记录 develop@30767a55 的双版本功能及已登记 Linux 3.32.0 Golden 通过，仅属于该历史提交。本次未查远端；早期“待推送”、旧 Golden 失败数及阶段判断不作为当前结论。
- 原始 804 项静态盘点与后续 677 项运行队列是不同口径：同目录 getter 或 Theme 候选不等于最终消费，缺少 Flutter 对应能力也不能靠新增空 Theme 字段核销。[静态审计](component-consumption-audit.json)、[候选审查](component-consumption-review.md) 保留来源。
