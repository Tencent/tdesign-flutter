# Popup 公开 Demo 对齐

## 背景

Popup Flutter Demo 虽覆盖了小程序公开页面的 7 个场景，但分组粒度、实例顺序、按钮文案和部分弹层结构不一致，并额外公开了嵌套 Popup。组件能力测试通过不能证明公开 Demo 已对齐。

## 目标

- 公开页面只保留“组件类型 / 基础弹出层”和“组件示例 / 应用示例”两个 Demo 块。
- 基础实例按顶部、左侧、居中、底部、右侧排列。
- 对齐 5 个基础实例和 2 个应用实例的文案、尺寸、头部与关闭按钮结构。
- 增加独立的双版本功能测试和 Flutter 3.32.0 Linux 明暗主题 Golden，并接入集中式 CI 调度器。

## 非目标

- 不删除 Popup 的嵌套能力；该能力保留在组件聚焦测试中。
- 不机械映射小程序 props/events，不新增 Popup 公开 API。
- 不在本 Spec 中决定默认动画时长；240ms 与 300ms 的权威基线仍需维护者讨论。

## 行为契约

- 页面说明为“由其他控件触发，屏幕滑出或弹出一块自定义内容区域。”。
- 基础顶部/底部为 240px 高，左侧/右侧为 280px 宽，居中为 240×240。
- 基础底部不显示标题栏；基础居中不显示外置关闭按钮。
- 带标题底部实例为 240px 高，只显示取消、标题文字和确定头部。
- 自定义关闭实例为 240×240，并显示面板外下方关闭按钮。
- 公开页面共 7 个触发按钮，不显示嵌套示例和 debug 单元测试模块。

## 验收标准

- [ ] 分组、说明、实例数量、顺序和按钮文案由 Demo Widget 测试精确断言。
- [ ] 基础底部与两个应用实例的关键结构、尺寸和关闭交互通过测试。
- [ ] 明暗主题完整页面 Golden 在 Flutter 3.32.0 Linux 可复现。
- [ ] Popup 组件测试、覆盖率目标、Demo 功能测试与 Golden 均进入 CI 实际调度入口。
- [ ] Popup 生产源码行覆盖率不低于 95%。
- [ ] Flutter 3.32.0 与 latest 严格 analyze、组件测试和 Demo 功能测试通过。
