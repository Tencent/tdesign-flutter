# 视觉比较证据

## 设计稿比较

`design/` 共 28 张，每张从左到右为：

1. Figma 原图；
2. `origin/develop` 与 Figma 的差异叠加，红色表示强差异，橙色表示连续低对比色差；
3. 当前源码与 Figma 的差异叠加，使用相同阈值和配准规则；
4. 当前源码的原始渲染，不叠加标记。

四列都从第一个公开标题开始，状态栏、Figma 头部与底部测试区域不进入比较。图底部同时记录 develop 与当前实现相对 Figma 的差异比例。该比例包含 Flutter 与 Figma 字体栅格差异，必须结合各自差异列中的红色区域和组件边界人工判断，不能单独作为通过阈值。

## Golden 比较

`golden/` 为仓库全部变更 Golden 的逐文件证据，每张从左到右为：

1. `origin/develop` 基线；
2. 精确 RGBA 差异，任一通道不同即标红；
3. 当前基线。

标题记录文件状态、差异像素数与最大通道差。新增基线的左栏为空白，删除基线的右栏为空白。`golden/manifest.tsv` 提供完整机器可读清单。
